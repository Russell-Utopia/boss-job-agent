# 分诊标签

工程技能使用五种标准分诊角色。本文件把这些角色映射到本仓库 GitHub Issues 实际使用的标签。

| 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估工单 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以交给 Agent 独立处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现或处理 |
| `wontfix` | `wontfix` | 确认不处理 |

当技能提到某个标准分诊角色时，使用表格中对应的 GitHub 标签。
