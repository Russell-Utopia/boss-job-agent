# 在单一后台进程中运行三条独立执行流程

BOSS Job Agent v1 使用一个常驻 Go 后台进程持有 SQLite，并在进程内分别运行岗位发现、岗位鉴定和首次沟通三个独立执行模块。操作界面只读取状态和提交用户命令；关闭界面不会停止执行，也不会为每个岗位发现运行创建独立进程、独立发送模块或内存中的 TaskPipeline。MVP 只实现 Web，具体选择见 ADR-0020，但后台模块不依赖某一种界面技术。

三个执行模块各自拥有 Worker 生命周期、租约、失败和重试控制，通过 SQLite 中的当前业务状态衔接，不依赖进程内消息传递才能恢复。后台进程重启后依据持久化状态和过期租约分别恢复三条流程；Pi 只作为岗位鉴定模块按需管理的子进程，浏览器 session 只作为岗位发现和首次沟通模块的执行适配器，不拥有业务生命周期。
