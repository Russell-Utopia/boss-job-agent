# 由用户手动刷新并版本化在线简历

BOSS 在线简历仍是搜索条件和 AI 岗位判断的唯一资料源，但程序只有在求职者于设置中显式点击“刷新在线简历”时才访问 BOSS，并把变化后的完整内容作为递增、不可变的版本保存在 `online_resume_versions`。刷新失败不创建版本、不改变当前版本；内容与当前版本一致也不递增版本号。一轮岗位发现只记录并始终采用开始时的当前版本，暂停、恢复或运行期间手动刷新都不能把它切换到新版本；要用新版本重新初筛，必须在旧运行完成或提前结束后创建新运行。待鉴定岗位真正开始执行时才独立记录届时当前版本、JD 和用户当前策略，因此刷新会影响尚未开始的鉴定，但不改变正在执行的鉴定。没有进入新鉴定的历史岗位继续保留旧结论及打招呼资格；系统不会因为当前简历版本变化扫描全库、撤回待打招呼工作或要求再次确认，求职者通过开启自动打招呼承担继续采用既有结论的选择。两个流程都不会自动刷新或动态修改简历。版本包括求职条件、工作经历、项目经历、教育经历和技能，但不包括电话、微信等不参与判断的敏感信息，由此可以还原每次搜索和鉴定实际使用的内容。
